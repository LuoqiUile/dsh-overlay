# dsh 插件安装教程（完整版）

> DeepSeek Harness（dsh）插件安装专项教程。本文所有命令均在 Windows + PowerShell 环境下实测通过。
> 配套文档：`其他设备部署说明.md`（整机三步部署）、`README.md`（项目总教程）。

---

## 一、安装前置（一次性准备）

| 步骤 | 命令 | 说明 |
| --- | --- | --- |
| 1. 安装 Node.js LTS | 官网下载 [nodejs.org](https://nodejs.org) 24.x LTS，默认路径 | 方案 A |
| 2. 放开脚本执行策略 | `Set-ExecutionPolicy RemoteSigned -Scope CurrentUser` | 否则 `dsh` 命令报"禁止运行脚本" |
| 3. 安装 dsh | `npm install -g @deepseek-ai/dsh` | 全局安装，入口 `dsh.cmd` |
| 4. GitHub 加速 | `git config --global url."https://gh-proxy.com/https://github.com/".insteadOf "https://github.com/"` | 国内直连常被重置，必须配置 |

> 注意：npm 11 及以上默认禁止依赖安装脚本，dsh 全局安装若报脚本错误，属正常通道限制，按 npm 提示处理即可；git 源插件不受影响。

## 二、插件安装的 4 种方式

### 方式 1：git 源安装（最常用，推荐）

```powershell
dsh plugin --profile web add "git+https://github.com/<作者>/<仓库>"
```

- 示例：`dsh plugin --profile web add "git+https://github.com/Zhenyu98/dsh-context-doctor"`
- 指定分支/版本：`"git+https://github.com/xxx/yyy#main"`（`#` 后跟分支名）
- 插件安装到 dsh 全局插件目录，配置档为 `web`

### 方式 2：dshmarket 商城（界面操作）

1. 运行 `dsh web`，浏览器打开 `http://127.0.0.1:3080`
2. 左侧进入 **dshmarket** 市场页，浏览/搜索插件
3. 点「安装」，按提示确认版本要求（个别插件要求 dsh 版本 ≥ 某版本，版本不足先去升级 dsh）

### 方式 3：npx 源安装（官方 npm 包）

```powershell
dsh plugin add "npx:<包名>"
```

- 示例：`dsh plugin add "npx:@anysearch/anysearch-dsh"`（需按该插件 README 处理版本豁免）
- 适用已发布到 npm registry 的插件

### 方式 4：本地目录 / skill 类

- **本地插件**：`dsh plugin add "file:<绝对路径>"` 或 `dsh plugin add "<目录路径>"`
- **skill 类**（如 distilly、gpt-image-2-style-library）：git 源安装后自动落入对应技能目录
  - 普通 skill → `~/.dsh/skills/<name>/`
  - 代理 skill → `~/.agents/skills/<name>/`

## 四、版本豁免（版本不足 / 版本要求报错）

装插件若报「requires dsh ^x.y.z」或「version not supported」：

```powershell
dsh plugin allow-version --accept-risk <插件包名>
```

- 示例：`dsh plugin allow-version --accept-risk @anysearch/anysearch-dsh`
- 作用：接受当前 dsh 版本风险，允许该插件加载

## 五、验证是否安装成功

```powershell
# 1. 命令行查看
dsh plugin list

# 2. 界面查看
dsh web → 浏览器打开 http://127.0.0.1:3080 → 插件管理页
# 3. 悬浮窗查看（已装 DSH 插件控制台时）
#    两列卡片实时罗列全部插件 + 状态灯
```

常见状态灯含义：`已启用`（绿色）/ `未启用`（灰色）/ `启动失败`（红色，看日志）。

## 六、开关 / 卸载 / 升级

| 操作 | 命令 |
| --- | --- |
| 查看 | `dsh plugin list` |
| 开关 | `dsh plugin toggle <包名>`（或悬浮窗/界面开关） |
| 卸载 | `dsh plugin uninstall <包名>` |
| 升级单个 | `dsh plugin update <包名>` |
| 检查可升级 | `dsh plugin check-updates` |
| 启用皮肤 | `dsh plugin use-skin <皮肤名>` |

## 七、常见排错

| 现象 | 原因与解决 |
| --- | --- |
| `dsh : 无法加载文件 ... 禁止运行脚本` | 执行策略未放开：`Set-ExecutionPolicy RemoteSigned -Scope CurrentUser` |
| git 安装超时 / 重置 | GitHub 直连被重置：配置 gh-proxy 加速（见前置第 4 步） |
| 装插件报「requires dsh 版本不足」 | 升级 dsh 或用 `allow-version --accept-risk` 豁免 |
| 装后不生效 / bundle 插件不加载 | 插件目录内有 `cordis.patch.yml` 时**必须用 insert 块**（开发者注意）；普通用户先 `dsh plugin toggle` 重启该插件 |
| 开关后功能异常 | 按官方判定执行：重启 dsh / 刷新页面 / 即时生效 |
| token 失效（401） | dsh 每次启动 token 变化，重启 dsh 即可；悬浮窗会自动重读 |

## 八、配置档（profile）说明

- dsh 支持多配置档，插件默认装到当前档；常用 `--profile web`
- 查看当前档：`dsh config get`
- 切换档：`dsh --profile <名称> ...`
