# DSH插件控制台 · 其他设备部署说明

> 打包版本：v0.1.26 · 构建时间：2026-09-24 · 支持 Windows 10/11 x64

## 一、前置条件（目标电脑必须满足）

1. **Node.js LTS**（建议 20+，本机验证环境 24.x）——官网或镜像安装
2. **安装 dsh**（DeepSeek Harness CLI，npm 全局安装）
3. **启动 dsh**：终端运行 `dsh web`（保持运行，端口 3080）

> 控制台依赖 dsh 的本地接口（`127.0.0.1:3080`）与登录 token 日志，**dsh 未运行时控制台会显示"未连接"**，插件列表为空。

## 二、安装方式（三选一）

### 方式 A：安装包（推荐正式使用）
- 运行 `DSH插件控制台-0.1.26-x64-setup.exe`
- 向导安装，可自选目录；自动创建桌面快捷方式与开始菜单项
- 安装完双击"DSH插件控制台"启动

### 方式 B：便携版（免安装、绿色）
- 把 `DSH插件控制台-0.1.26-x64-portable.exe` 放到任意目录（建议放 dsh 同盘）
- 双击直接运行，首次会自解压（稍慢几秒）

### 方式 C：自动拉起（推荐）—— 安装 dsh-overlay-launcher 启动钩子
安装包/便携版可手动打开；要**终端打开 dsh 时自动拉起悬浮窗**，再装启动钩子插件：
1. 把归档中 `16-dsh-overlay-launcher` 文件夹复制到目标电脑
2. 运行：`dsh plugin --profile web add "dsh-overlay-launcher 所在目录"`
3. 重启 dsh（或 dshmarket 重启）——之后每次 `dsh web` 都会自动拉起悬浮窗
4. 若悬浮窗不在默认位置，设环境变量 `DSH_OVERLAY_EXE` 指向悬浮窗 exe（可选）

## 三、使用说明

- 打开后自动两列罗列 dsh 已装全部插件（含中文名、状态、开关）
- 开关插件：官方判定弹窗提示"重启/刷新/即时生效"
- 顶部按钮：状态诊断（扳手）/ 设置 / 回收站 / 置顶 / 折叠 / 退出
- 折叠：窗口收成顶部一小条（42px），点展开恢复
- 悬停插件卡片：并排显示使用说明；展开插件：查看功能、版本/更新、应用主题、删除插件
- 设置：整体颜色、背景透明度、字体大小、文字加粗
- 回收站：删除的插件移入回收站，可一键恢复或彻底删除

## 四、路径与数据（跨设备自适应，无需改配置）

| 项目 | 位置 |
| --- | --- |
| 回收站 | `%USERPROFILE%\.dsh\recycle`（本机若存在旧目录 `C:\deepseek harness\dsh-回收站` 则沿用） |
| 运行日志 | `%APPDATA%\DSH插件控制台\error.log`（异常兜底记录） |
| token 来源 | 自动探测 `%APPDATA%\npm\dsh-web.log` / PATH 中 dsh.cmd 旁日志 |
| dsh 命令 | 自动探测（环境变量 `DSH_CMD` 可手动指定） |

## 五、常见问题

| 现象 | 处理 |
| --- | --- |
| 打开提示"未连接/HTTP 0" | dsh 未运行 → 终端运行 `dsh web` |
| Windows SmartScreen 拦截 | 未签名软件提示，点"更多信息 → 仍要运行" |
| 插件列表不更新 | 点顶部刷新状态 / 重启 dsh |
| 端口被占用 3080 | 关闭占用程序后重启 dsh |
| 便携版被杀毒误报 | 添加到信任区（未签名应用常见） |
